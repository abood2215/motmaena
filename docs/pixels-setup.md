# تفعيل بكسلات Meta وTikTok وSnap

البكسلات جاهزة في كود الموقع، لكنها **متوقفة**. لا يُحمَّل أي بكسل إلا إذا تحقق الشرطان معاً:
1. وُضع معرّف البكسل في لوحة التحكم.
2. الموقع يعمل على السيرفر الحقيقي (`APP_ENV=production`). النسخة المحلية والتجريبية لا ترسل شيئاً.

## قبل التفعيل (مطلوب من الإدارة)
- [ ] **معرّف كل بكسل** من حساب الإعلانات الذي يملكه المركز:
  - Meta Pixel ID: أرقام فقط، مثل `123456789012345`.
  - TikTok Pixel ID: حروف وأرقام، مثل `C1ABCDEF2GHIJ3KLMN4O`.
  - Snap Pixel ID: بالشكل `1a2b3c4d-1234-5678-9abc-1234567890ab`.
- [ ] **اعتماد سياسة الخصوصية** ونشرها، وفيها ذكر البكسلات وأدوات القياس.
- [ ] **قرار آلية الموافقة:** هل نعرض نافذة موافقة على الكوكيز قبل تشغيل البكسلات؟ (غير موجودة حالياً).

## إعدادات في حسابات الإعلانات (بدون كود)
هذه الإعدادات تمنع وصول بيانات العملاء للمنصات:
- **Meta (Events Manager ← Settings):**
  - أطفئ **Automatic advanced matching**.
  - **Core setup:** لا تُفعّل تتبّع الأزرار التلقائي. الكود يوقفه أيضاً (`autoConfig` = false).
- **TikTok (Events Manager ← Settings):** أطفئ **Automatic advanced matching**.
- **Snap (Events Manager):** لا تُفعّل أي مطابقة بالبريد أو الهاتف.

## طريقة التفعيل
1. لوحة التحكم ← المحتوى ← **التتبّع والإعلانات**.
2. الصق كل معرّف في خانته، ثم احفظ. تقبل الخانة المعرّف وحده. إذا لُصق سطر كود كامل، يُستخرج المعرّف تلقائياً.
3. لإيقاف بكسل: امسح خانته واحفظ.

## الأحداث التي يرسلها الموقع

| ما يفعله الزائر | GA4 | Meta | TikTok | Snap |
|---|---|---|---|---|
| يفتح أي صفحة | `page_view` | `PageView` | `page` | `PAGE_VIEW` |
| يفتح صفحة دورة أو عرض | `view_item` | `ViewContent` | `ViewContent` | `VIEW_CONTENT` |
| يضغط رابط تسجيل | `register_click` | `RegisterClick` (custom) | `ClickButton` | — |
| يضغط زر الدفع | `begin_checkout` | `InitiateCheckout` | `InitiateCheckout` | `START_CHECKOUT` |
| يتم الدفع (صفحة التأكيد) | `purchase` | `Purchase` | `CompletePayment` | `PURCHASE` |
| يرسل طلب استشارة، أو طلب د. طارق، أو "بلّغني" | `generate_lead` | `Lead` | `SubmitForm` | `SIGN_UP` |
| يضغط أي زر واتساب | `contact` | `Contact` | `Contact` | — |

**ما يُرسل:**
- اسم الدورة أو رمزها، والسعر والعملة.
- رقم العملية (`REG-123`) عند الدفع.
- مكان الزر (`link_location`).

**لا يُرسل أبداً:** الاسم، أو الهاتف، أو البريد، أو نوع الاستشارة، أو الملاحظات، أو نص رسالة الواتساب.

## الاختبار بعد التفعيل
1. ثبّت إضافات Chrome التالية:
   - **Meta Pixel Helper**.
   - **TikTok Pixel Helper**.
   - **Snap Pixel Helper**.
2. افتح الموقع الحقيقي في نافذة عادية، مع إيقاف مانع الإعلانات.
3. نفّذ الخطوات التالية، وتأكد من ظهور الحدث في كل إضافة:
   - افتح الرئيسية: يظهر `PageView`.
   - افتح صفحة دورة: يظهر `ViewContent` مع اسم الدورة والسعر.
   - اضغط "سجّل" من الرئيسية:
     - Meta: يظهر `RegisterClick`.
     - TikTok: يظهر `ClickButton`.
   - اضغط زر واتساب: يظهر `Contact`.
   - عبّئ نموذج الدورة باسم "اختبار" واضغط الدفع، **ولا تدفع**:
     - يظهر `InitiateCheckout`.
     - احذف التسجيل التجريبي أو علّمه من لوحة التحكم.
4. **في Meta Events Manager ← Test events:** افتح كل حدث وتأكد أن **Parameters** لا تحتوي أي بيانات شخصية.
5. `Purchase` يُختبر فقط مع أول عملية دفع حقيقية يجريها المركز.

## اختبارات آلية موجودة
- **`tests/Feature/PixelReadinessTest.php`** يتأكد من التالي:
  - لا يُحمَّل أي بكسل بدون معرّف، ولا خارج الموقع الحقيقي.
  - تتبّع Meta التلقائي متوقف.
  - لا توجد مطابقة ببيانات العملاء.
- **`tests/Feature/MeasurementEventsTest.php`** يتأكد أن الأحداث لا تحمل بيانات شخصية.
